# QuickFileLocator
A simple file search GUI application created with the help of Claude.

# ファイル検索アプリ

このアプリケーションは、指定した検索文字列を含む文書（.docx、.txt）をローカルフォルダー内で検索し、結果を表示するデスクトップアプリケーションです。

## 特徴

- `.docx`および`.txt`ファイルのサポート（拡張子の大文字・小文字は区別しません。`.docx`は本文と表の中を検索します）
- AND検索 (`&&`)、OR検索 (`||` または空白)、フレーズ検索（引用符で囲まれた文字列）
- 検索先フォルダーの指定（サブフォルダーも検索します）
- 検索進捗の表示と、検索のキャンセル
- 検索結果のリストアップ（ダブルクリックでファイルを開く、選択してコピー）
- 読み取れなかったファイルと、その理由の一覧表示

## 動作環境

- Python 3.10 以上
- Windows / macOS

| 環境 | 確認状況 |
| --- | --- |
| macOS (Apple Silicon) | Python 3.10 / 3.12 / 3.14 で自動テスト、Python 3.12 で起動と検索を確認済み |
| Windows | このバージョンでは未検証（`.github/workflows/ci.yml` で自動テストを実行する設定を追加しています） |

## インストール方法

このアプリケーションを実行するには、以下の手順に従ってください。

1. このリポジトリをクローンまたはダウンロードします。
2. 必要なPythonパッケージをインストールします：
```
pip install -r requirements.txt
```
3. アプリケーションを起動します：
```
python main.py
```

検索先フォルダーを指定して起動することもできます：
```
python main.py "C:\Users\me\Documents"
```

## 使用方法

1. 「検索先」に検索したいフォルダーを指定します。「参照...」から選ぶこともできます。
   - 初期値は、`python main.py` を実行したときのカレントディレクトリです。
   - exe化して使う場合の初期値は、exeを置いたフォルダーです。
2. 検索バーに検索文字列を入力し、「検索」ボタンをクリック（またはEnterキー）で検索を開始します。
3. 一致したファイルが一覧に表示されます。ダブルクリックすると、関連付けられたアプリでファイルを開きます。
4. 検索を途中でやめるときは「キャンセル」をクリックします。それまでに見つかった結果は残ります。

### 検索文字列の書き方

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| `A && B` | AとBの両方を含む | `見積 && 2024年` |
| `A \|\| B`、`A B` | AとBのどちらかを含む | `見積 請求` |
| `"A B"` | 空白や `&&` `\|\|` を含む文字列を、そのまま1つの語として探す | `"project plan"` |
| `\"` | 引用符 `"` そのものを探す | `\"重要\"` |

- `&&` は `||` や空白より後に評価されます。`A B && C` は「（AまたはB）かつC」です。
- 既定では大文字と小文字を区別します。「大文字と小文字を区別」のチェックを外すと区別しません。
- 全角スペースも区切りとして扱います。

### 除外されるファイル

次のファイルは検索できないため、検索完了後に理由とともに「除外されたファイル」に表示されます。

- 壊れている、またはパスワードで保護されているなど、Word文書として開けない `.docx`
- Wordが編集中に作成する一時ファイル（`~$` で始まる `.docx`）
- 文字コードを判定できない `.txt`
- 100MBを超えるファイル
- アクセス権がなく読み取れないファイル・フォルダー

### 文字コードについて

`.txt` は、BOM、JIS（ISO-2022-JP）、UTF-8、EUC-JP・UTF-16などの自動判定結果、シフトJIS（CP932）の順に読み取りを試みます。日本語の文書を想定しているため、UTF-8でない短い文章はシフトJISとして扱います。そのため、西欧語などシフトJIS以外の1バイト文字コードで保存されたファイルは、英数字以外の部分が正しく検索できないことがあります。

## 開発者向け情報

このプロジェクトはPythonとPyQt5で開発されました。貢献したい場合は、プルリクエストを送ってください。

### 構成

| ファイル | 役割 |
| --- | --- |
| `main.py` | 起動スクリプト |
| `quickfilelocator/query.py` | 検索文字列の解析と本文との照合 |
| `quickfilelocator/readers.py` | `.txt` / `.docx` から本文を取り出す処理 |
| `quickfilelocator/search.py` | フォルダーの走査と検索（Qtに依存しません） |
| `quickfilelocator/gui.py` | 画面と、検索を実行するスレッド |
| `quickfilelocator/app.py` | 起動時の組み立て |
